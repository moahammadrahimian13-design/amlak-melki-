# پروژه املاک ملکی (نسخه ۵)

این مخزن شامل کدهای کامل پروژه سیستم مدیریت املاک و مستغلات است.

## بخش‌های اصلی پروژه:
*   **پنل مدیریت (admin):** بخش مدیریت کاربران و آگهی‌ها.
*   **بک‌اند (backend_pg):** سرور و پایگاه داده PostgreSQL.
*   **فرانت‌اند (v3_base):** رابط کاربری اصلی.
*   **سئو (web-seo):** تنظیمات مربوط به بهینه‌سازی موتور جستجو.
*   **داکر (docker-compose.yml):** فایل اجرای یکپارچه پروژه.

## نحوه اجرا:
برای اجرای پروژه، از دستور `docker-compose up -d` استفاده کنید.
